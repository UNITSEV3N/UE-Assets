# UE-Assets

Backported Unreal Engine 5 prototype materials for Unreal Engine 4.

## Overview

Unreale Engine 5 shups with a set of default materials (grid). UE 4.27 doesn't include them, so I decided to create this repository to provide a version for it.

This isn't a major rewrite of the materials, just a straight copy-over with no significant changes. 

## Whats Include

### Master Materials
- `M_Prototype_Grid`
- `M_Solid`

### Child Materials Instnaces
- `MI_Grey_Prototype_Grid`
- `MI_Orange_Prototype_Grid`
- `MI_White_Prototype_Grid`

### Textures
- `T_GridChecker_A`

## Compatibility

- **Engine Version:** Unreal Engine 4.27

## Installation

1. Download or Clone this repo
```bash
git clone https://github.com/UNITSEV3N/UE-Assets.git
```

2. Migrate the `Asset/Prototype` folder to new project's `Content` direcotry
